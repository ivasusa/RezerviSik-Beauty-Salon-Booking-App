# RezerviŠik – Booking System

RezerviŠik is a full-stack web application for online booking and management of beauty salon appointments.

## Features
- User roles:
  - Client
  - Staff
  - Salon Owner
  - System Administrator
- Online appointment booking and cancellation
- Real-time schedule management
- Notifications (Gmail)
- Reviews and ratings system
- Advanced filtering and search
- Business analytics for salon owners

## Functionality
- Authentication & authorization
- Service and staff management
- Calendar integration (Google Calendar)
- Prevention of double bookings
- Automated reminders and notifications

## Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Django
- Database: MySQL
- APIs: Google Calendar API

## Testing
- Unit testing
- Selenium WebDriver tests
- Selenium IDE (SIDE) tests

## Project Components
- System design & documentation
- UML diagrams and database modeling
- Full implementation (frontend + backend)
- Automated testing
